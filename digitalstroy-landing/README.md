# DigitalStroy — лендинг

Готовый статический сайт performance-агентства DigitalStroy, собранный из
дизайн-макета (`design_handoff_digitalstroy_landing`). Чистый HTML/CSS/JS без
сборки и зависимостей — открывается двойным кликом или раздаётся любым статическим хостингом.

## Файлы

| Файл | Что это |
|------|---------|
| `index.html` | Вся страница: hero, услуги, платформы, аутсорс-маркетолог, ниши, кейсы, философия, процесс, **интерактивный калькулятор**, тарифы, FAQ, CTA, футер, модалка заявки, плавающая кнопка бота. |
| `calculator.html` | Тот же калькулятор отдельным файлом — для встраивания на другую страницу (блок Tilda или `<iframe>`). |
| `assets/` | Изображения (лого, hero, фото, иконки площадок). |

## Что заложено

- **Дизайн-токены** дизайн-системы вшиты в `:root` (цвета, типографика, отступы,
  тени, motion). Шрифты — Simonetta + Inter с Google Fonts.
- **Компоненты** (`Button`, `Tag`) переписаны как обычные CSS-классы — рантайм
  прототипа (`support.js`, `_ds_bundle.js`) не используется.
- **Анимации** из макета сохранены: печатающиеся eyebrow-надписи, бегущая строка,
  канвас точек, последовательная подсветка шагов, hover-состояния карточек.
  Всё уважает `prefers-reduced-motion`.
- **Адаптив** добавлен (в макете он не был проработан): на планшете/мобайле
  многоколоночные сетки схлопываются, панель итога калькулятора липнет снизу.

## Калькулятор

Логика по ТЗ: UI строится из объекта `PRICING`, пересчёт мгновенный, при 2+
направлениях — скидка 15 % на разовую часть (бейдж + зачёркнутая цена),
помесячные позиции считаются отдельно, у трафика — сноска «под задачу».

По клику «Получить точную смету →» в консоль пишется `payload` и человекочитаемое
резюме, затем вызывается хук `window.DSCalcSubmit(payload, summary)`:

- на лендинге он открывает модалку с формой заявки;
- в standalone-версии просто логирует — здесь подключается отправка в бота/вебхук.

## Точки интеграции

- **Форма заявки** — модалка грузит форму Bitrix24 (loader `inline/218`). Любой
  элемент с атрибутом `data-open-form` открывает её.
- **Telegram** — кнопки и ссылки ведут на `t.me/digitalstroyru` и бота
  `t.me/DigitalStroy_it_bot`.
- Реквизиты ИП и контакты в футере — реальные из макета; проверьте перед
  публикацией.

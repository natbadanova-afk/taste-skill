# DigitalStroy — лендинг «Лиды для B2B»

Готовый статический сайт, собранный из дизайн-референса `design_handoff_b2b_landing`
(формат Design Component). Дизайн, тексты, анимации и поведение перенесены
пиксель-в-пиксель в самодостаточный `index.html` — без рантайма прототипа
(support.js / React / Babel через CDN больше не нужны).

## Что внутри
- `index.html` — вся страница: разметка, inline-стили, эффекты и вся интерактивность
  на чистом ванильном JS.
- `_ds/.../tokens/*.css` — дизайн-токены DigitalStroy (цвета, типографика, spacing/motion).
- `assets/` — логотип и фото.

## Аналитика
В `<head>` подключены:
- **Яндекс.Метрика** — счётчик `110772095` (webvisor, clickmap, ecommerce, точный отказ).
- **BotFaqtor** — `_ab_id_ = 173857`, `https://cdn.botfaqtor.ru/one.js`.

## Интерактив
Работает без внешних зависимостей: плавный скролл по кнопкам и якорям, аккордеон FAQ,
эффект печатной машинки в блоке «Специализация», подсветка tech-grid за курсором,
мерцающие искры, анимированная SVG-воронка, отправка формы → экран «Получили ваш бриф».

> Форма пока без бэкенда: по submit показывается экран благодарности.
> Подключите отправку в свою CRM/бота в обработчике `form.addEventListener('submit', …)`
> внутри `index.html`.

## Внешние ресурсы
Страница обращается наружу только за: Google Fonts (Simonetta + Inter),
Яндекс.Метрикой и BotFaqtor. Всё остальное лежит рядом и работает офлайн.

## Как открыть / задеплоить
Это обычная статика — достаточно раздать папку любым статическим хостингом
(GitHub Pages, Nginx, S3 и т.п.) или открыть `index.html` локально через простой сервер:

```bash
cd site && python3 -m http.server 8080   # → http://localhost:8080
```
